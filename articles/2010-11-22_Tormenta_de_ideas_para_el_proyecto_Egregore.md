# Tormenta de ideas para el proyecto Egregore

Damos por concluida la programación de las herramientas para descargar las bases de datos en formato de texto de diferentes servidores.


Los exprimidores de datos se pueden descargar aquí, para que puedan ser utilizados por los voluntarios que harán los trabajos de investigación que se propongan en esta tormenta de ideas.


Los que no están al corriente de este proyecto pueden ponerse al día mirando el siguiente vídeo de un coloquio que se hizo para la asignación de tareas a programadores.











El objetivo de este post es recoger propuestas para analizar los datos que se pueden bajar con las herramientas citadas anteriormente. También habrá que reclutar voluntarios para programar las herramientas que se necesiten para desarrollar los análisis que se propongan y que a la mayoría le parezcan interesantes.


En términos generales, se trata de analizar la estacionalidad de todos los productos, para saber en qué meses o periodos del año se suele producir una pauta que se pueda cuantificar y aprovechar.


Este análisis también se puede hacer con spreads o mariposas de cualquier producto. Espero que los que tienen más experiencia en la estacionalidad propongan cosas interesantes. Como yo siempre he trabajado a media jornada, hasta este momento no he tenido tiempo para dedicarme a analizar concienzudamente la estacionalidad de cada producto. Creo que entre todos puede salir un trabajo importante y muy rentable.


Otra cosa que se podría estudiar: las pautas de productos y spreads al acercarse al vencimiento. Con el estudio que se hizo sobre los tipos de interés del dólar, y que fue el que inició este proyecto, se pudo ver que el mismo spread era rentable para estar comprado faltando 3 años, pero había que tenerlo en posición corta en los últimos meses.


Otra cosa que hay que hacer es ver la estacionalidad entre spreads de diferentes productos: trigo menos maíz, vaquitas menos cerditos, oro menos plata, complejo de la soja, cacao, azúcar, etc.


También haremos un estudio sobre los índices de renta variable: meses alcistas, día de la semana, etc. Todo ello por separado, cuando se produce a favor o en contra de la primaria.


Se le hará una opción a ETCHART para que pueda graficar esta base de datos en formato de texto con los siguientes formatos:



Un perpetuo cogiendo el mes más cercano al vencimiento. Se podrá elegir cuántos días antes del vencimiento se pasa al siguiente. También se podrá dibujar desde un sólo año hasta 50 que tienen algunos productos. Todo ello con un producto por separado o con cualquier combinación.

Se podrá hacer el gráfico de un solo vencimiento en concreto, sólo o combinado con otro.

Se podrá hacer un continuo que sólo graficará los meses exactos de cada año que se le pidan.






Todas estas posibilidades se podrán guardar en listas de gráficos para verlas o pasarlas a otros usuarios.


Para que las propuestas y sugerencias sobre el proyecto Egregore no queden desperdigadas en los comentarios de diferentes post y estén agrupadas y accesibles, espero que se pongan todas aquí.


Cuando se empiecen los análisis, para cada nuevo resultado de cada estudio se abrirá un hilo en este foro dedicado exclusivamente al proyecto Egregore. En cada hilo, el autor del estudio podrá aclarar las dudas de los lectores. De esa manera, todos los análisis se podrán ver agrupados pinchando en el citado foro.


Espero vuestras propuestas y vuestra colaboración en este proyecto. Tenemos todo lo necesario para que esto sea un éxito. Si no llega a buen puerto, luego no nos podremos quejar, será exclusivamente culpa nuestra.
