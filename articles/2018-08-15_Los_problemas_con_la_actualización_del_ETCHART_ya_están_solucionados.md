# Los problemas con la actualización del ETCHART ya están solucionados

ACTUALIZACIÓN DE ETCHART


Para no tener que descargar la base de datos entera, se puede actualizar el programa descargando solamente los archivos ejecutables.


Instrucciones de actualización para Windows: Es un archivo comprimido auto-ejecutable. Se coloca dentro de la carpeta ETCHART, borramos la carpeta SOFT y ejecutamos el archivo comprimido.


Descarga del fichero comprimido con el software actualizado para Windows
