# El mercado PINK incluido en el ETCHART

Ya está disponible la última versión del software y base de datos ampliada para los nuevos gráficos en cinco dimensiones ETCHART y las tablas en tres dimensiones TD3D


Se ha ampliado la base de datos con 14.000 gráficos al incluir el mercado PINK y el OTCBB


Aunque todavía se habrá escapado alguno, se han corregido todos los splits de todos los mercados. Debido a ello, es conveniente descargar la base de datos entera. En las próximas actualizaciones sólo se pondrá lo nuevo, pero esta vez hay demasiados valores modificados para mandarlos por separado.


Como la base de datos ya va pesando bastante, cuando se incluya un nuevo mercado se mandará ese mercado comprimido sin tener que descargar el resto de archivos. Espero que ésta sea la última vez que hay que descargarlo todo.


No se ha puesto una lista del mercado PINK porque no caben tantos valores en un post. Si se pide la lista de este mercado en ETCHART, salen todos los chicharritos con el nombre corto y el largo.
